# 历史竞争信息的有界缓存验证计划

本轮检验过去阶段的竞争类别能否补充当前预测。先核验跨阶段像素对齐和固定两类候选集的错误恢复率，只有预定筛查通过才拟合低维探针。所有教师、学生参数和 BN buffer 保持冻结。本轮使用已查看过的数据做开发筛查；已有 validation 仅用于描述，不是未触及确认集。

## 问题与顺序

在当前 MC 和 margin 相近时，历史阶段支持的竞争类别是否具有超过当前 Top-2、普通历史集成和类别对应打乱的增量？本轮首先检验这个问题的一个具体实现：保留当前首选类，再加入过去阶段最强的非首选类。只有这个固定候选方案表现出可重复的错误恢复增量，才投入新的正确性评分器。

执行顺序固定为：计划和机器协议提交 → 合成检查 → 不可变源码发布 → D_rel 全部对齐核验 → D_rel 候选筛查并写入 gate → 条件性低维探针 → 已查看 validation 描述 → 汇总和 GitHub 同步。不得先看 validation 再决定是否拟合。

候选恢复率是本轮投入探针的充分条件，不是历史信息有效的必要条件。筛查失败不能证明“即使候选类别不变，历史信息也无法区分错误”；报告须保留这个范围。

## 输入与像素对齐

固定旧 BN 保存策略下 VOC seed42 的 early/middle/late 三个导出目录，仍使用 D_sup=1,191、D_rel=132、validation=1,449 的原划分。只比较 early→middle 和 middle→late。early 没有更早缓存，不补造历史；两个区间不是独立教师重复。

每个角色三阶段必须具有相同图像集合，且逐图满足以下要求：

- image_id、role、原图尺寸、有效像素数相同；每个 ID 唯一，角色无交叉。
- 比较完整原缓存的 pixel_indices、yx、GT、boundary，全部逐元素相同；先检查完整数组，再取原顺序前 1,024 个像素。
- 索引在范围内且不重复，yx 与扁平索引可相互还原；logits 维数为 21，有限且与 GT 长度一致。
- 每阶段缓存 correct 必须等于该阶段 argmax 与 GT 的比较；checkpoint、prototype、协议身份与原 manifest 一致；所有使用分片核验 SHA256。
- 出现缺图、错位、GT 不一致、身份或哈希不一致即中止，记录工程失败；不得按可用交集删图或插值后继续作主结果。

像素权重为原图有效像素数除以实际抽样数。历史特征只允许过去 checkpoint，同一图像的所有阶段始终位于同一 CV fold。固定沿用 `bounded_score_audit_20261023` 的图像划分，不寻找有利划分。

## 不拟合的候选恢复率筛查

记当前分布为 p、过去分布为 u，当前首选类 a=argmax p。每个方法都输出恰好两个不同类别 {a,c}，原伪标签 a 不被替换。并列时取最小类别编号。

| 方法 | 第二候选 c |
| --- | --- |
| now | 当前 p 中除 a 外的最大值，即当前 Top-2 |
| history，唯一待检候选 | 过去 u 中除 a 外的最大值 |
| arithmetic | (p+u)/2 中除 a 外的最大值 |
| geometric | (log p+log u)/2 中除 a 外的最大值 |
| sham401–405 | 打乱过去非 a 类别对应后，重复 history 的同一规则 |

没有候选集大小、混合系数、温度或类别筛选搜索。几何平均也保留为普通集成控制，避免把概率乘积重新命名为新机制。

主指标 error_recovery = 加权“当前教师错误且 c 等于 GT”像素数 / 加权当前教师错误像素数。它衡量第二候选能覆盖多少当前错误，不是实际纠错率或训练增益。另报集合真类包含率、替换候选后新增恢复和丢失恢复的质量、候选是否变化、历史与当前同错/异错，以及相同集合大小下的净收益。

固定范围为全体像素、MC≥0.95、MC≥0.995、历史首选与当前首选是否一致、历史第二候选与当前 Top-2 是否一致、原型严格冲突与非冲突。MC×margin、预测类、GT 边界分层完整保留空组和支持不足组。GT 边界仅作诊断，不作评分特征。

主估计量是全部 D_rel 图像质量之比，因为这些候选没有跨 fold 拟合和分数尺度问题。另报逐折数值。2,000 次配对 bootstrap 重采样完整 D_rel 图像池，包括相关子组中零像素的图像；两个区间使用相同图像抽样。所有方法使用同一重采样。

### 类别对应打乱

固定种子 401–405；按 image_id、pixel index 和种子确定过去非 a 类 logits 的置换。当前 logits 和过去 a 的 logit 不变，因此过去 MC、entropy、p(a)、过去首选是否等于 a 均保持，类别对应被改变。不同分块必须产生相同置换。逐像素验证这些不变量。

筛查没有拟合模型，所以此阶段的对照是固定候选规则本身。五次打乱分别计算指标后求均值，不平均概率，不解释成精确置换检验 p 值。只有进入探针阶段，才对五个打乱版本分别重新拟合完整历史候选与回退策略。

### 筛查继续条件，必须全部满足

1. 对齐与身份核验全部通过；两个区间 MC≥0.95 范围各至少 20 张含错图、20 张含正确像素图、100 个错误和100 个正确抽样像素。
2. middle→late 的高 MC error_recovery 中，history 相对 now、arithmetic、geometric、五次 sham 指标均值的四个差值，98.75% 配对图像区间下界均大于零。
3. late 相对 now 的恢复率点增量至少 1 个百分点；early→middle 四项对应点差均大于零。
4. late 点估计超过每一个 sham；两个区间的全体像素 history−now 恢复率点差均非负。

若不满足，写入 `screen_gate.json` 并跳过所有新探针拟合。仍完成固定的基线、全部打乱结果、分层、validation 描述及对齐报告。支持量不足列为“筛查证据不足”，不能改成效果为零。

## MC＋margin 与普通历史集成的错误排序

即使筛查未过，也完成冻结排序描述。当前错误始终定义为当前 a≠GT，不能用集成的 argmax 改变评价目标。

比较 raw MC、margin、entropy、此前已保存的 MC/MC＋margin 评分器，以及 arithmetic 对 a 的概率、geometric 对 a 的概率、过去 u(a)、过去 log u(b)−log u(a)，其中 b 为当前第二类。所有概率和 logit 使用稳定 FP64 计算。无新的校准拟合。

复用 `runs_93cb036e` 已保存的外折和最终 MC/MM 模型，先核验完成收据、模型文件哈希、图像 fold 与预测重放；D_rel 使用对应外折模型，validation 使用原全 D_rel 最终模型。不得复用其包含原型的 G/S/T 作为 MC/MM。

D_rel 排序主表为三个折内指标等权平均，pooled 另列；报告错误 AP、AUROC、风险覆盖曲线、P@90 和 C@95/C@98。冻结原始分数与 MM 均用同一估计量。此项描述不替代候选恢复率门槛，不据有利排序结果重开失败筛查。

## 仅在筛查通过后执行的低维探针

先在 D_rel 做三折外层、三折内层图像 CV。当前 MC 单调校准、线性/加性 MC＋margin 及精确零回退使用既有定义；加性折点为训练折加权 25/50/75% 分位数，去除常量、重复和相反等价基函数。

| 家族 | 新增输入 |
| --- | --- |
| static | 在固定 MM_additive 上加入当前 entropy 的线性修正 |
| H0 普通历史 | 过去 MC、entropy、u(a)、首选变化指示、arithmetic 的 logit p(a)、geometric 的 logit p(a) |
| H1 类别对应 | H0 的全部输入，再加过去 log u(b)−log u(a)、history 候选等于 b、b 在过去 Top-2 内的指示 |

修正都以固定 MM_additive 为 offset，用全体像素拟合正确性；H0/H1 分别作为整体低维线性候选，不加入交互或 MLP。候选集合嵌套包含较简单形式，以内层 OOF 加权 NLL 选择；改善≤1e−5 时回退较简单候选。最终形式由全 D_rel 候选 OOF NLL 选择，再全量重拟合。

全批 FP64 Newton，L2=0.001，最多 100 步，最大梯度阈值 1e−7，最多 40 次线搜索；不搜索优化种子或预算。五次打乱都重算历史/集成输入，独立拟合 H0/H1 及回退策略。全部 D_rel 拟合完成并冻结模型、选择及门槛后才读 validation。

探针主比较为 late 高 MC 的 H1−MM、H1−static、H1−H0、H1−五次 refit sham 的平均 AP，各用 98.75% 图像区间。继续提出独立确认的必要条件：四项下界均>0、H1−MM≥1 AP 点、两个区间四项点差均>0、两个区间总体 H1−MM 的95%下界>−0.5点、late 高 MC 的 AP/P@90/C@95 不低于 H0/MM 和原始 arithmetic/geometric。此门槛通过也不自动启动教师训练。

## 时间与结论边界

筛查上限 2 小时；若允许探针，另限 4 小时。超时、非有限值、未收敛或身份不一致按工程失败记录，不当作研究阴性结果。不中途改变候选、采样量、范围或停止条件。

所有数据来自已查看的旧 BN 教师缓存。跨阶段比较可能包含快照状态差异；本轮不能识别训练历史变化与 BN 保存偏差的纯因果贡献。已有132张 D_rel 的反复开发也限制了泛化解释。若筛查和探针都通过，下一步仍需另行登记正确快照、独立种子或未使用数据的确认。
